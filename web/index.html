    Entry types

    What do the roles do?
  • Needs cover – e.g. “Day care closed”. A weekday with this entry and nothing that covers it is flagged as a gap.
  • Covers – e.g. “Vacation Dad”. Covers a “needs cover” day.
  • Day off – e.g. “Holiday”. Covers everything and doesn't count as a used vacation day.
  • Normal – just a color, no coverage logic.

    Subscribe on this device

    How to add it to iCloud
    1. iPhone / iPad: tap “Subscribe on this device” above (or Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar, and paste the URL).
    2. Mac: Calendar → File → New Calendar Subscription…, paste the URL, set Location to iCloud so it syncs to all your devices, and pick an auto-refresh interval.
    3. A subscription stored in iCloud (Mac, Location “iCloud”) appears on all your Apple devices and on iCloud.com.

    How it works
    
      
    
    
    
    
      
    TapSelect a day; tap another day to move the selection
    
      
    Long-press + dragSelect a range of days
    
      
    RangeTap a start day, then “Range”, then the end day
    
      
    Multi-selectTurn it on, then tap days to add or remove them; long-press + drag adds a range
    
      
    ⋯ menuUndo / redo
    
      
    Click / dragSelect a day / a range of days (across months)
    
      
    Shift + clickExtend the selection
    
      
    Ctrl/⌘ + clickAdd single days to the selection
    
      
    Type button or 1–9Toggle that entry on the selected days (a day can have several)
    
      
    Del / BackspaceClear the selected days
    
      
    Ctrl+C / X / VCopy / cut / paste. Pasting onto a larger selection repeats the copied days to fill it.
    
      
    Drag the ▪ handleRepeat the selected days forwards or backwards
    
      
    Arrow keysMove (with Shift: extend the selection)
    
      
    Ctrl+Z / Ctrl+YUndo / redo
    
      
    N / double-clickAdd an icon or comment to the selected days
    
      
    Ctrl/⌘ + + / − / 0Zoom the calendar in / out (fewer or more days at once) / reset
    
      
    GJump to the next day that still needs cover
